# MediSafe – Smart Medicine Expiry Reminder System 

A beautiful, secure, and fully functional web app that helps you track home medicines and get **color-coded alerts** before they expire.

## Features
- User Registration & Login (with password hashing)
- Color-coded dashboard: Red (Expired) | Yellow (Expiring Soon) | Green (Safe)
- Add, Edit, Delete, Mark as Used/Discarded
- Live Search + Filter by Type + Sort by Expiry
- Fully Responsive (Mobile + Desktop)
- Success messages after every action

## Tech Stack
- PHP + MySQL (PDO for security)
- Tailwind CSS (via CDN)
- XAMPP Local Server

## How to Run
1. Import `medisafe_db.sql` into phpMyAdmin
2. Put all files in `htdocs/medisafe`
3. Start Apache & MySQL in XAMPP
4. Open: http://localhost/medisafe
